# ModuFlex v0.2.0b1

- Был произведён переход с фреймворка Pyrogram на фреймворк Kurigram. Kurigram - это современный форк Pyrogram, который содержит все современные функции Telegram API.
- Создан класс Parameters, для удобного парса параметров в команде. Подробнее в https://flexyyyapk213.github.io/ModuFlex/contribution.html#convenient-parser
- Теперь в команде help можно искать плагины/команды с помощью регулярного выражения (или по словам, если проще). Для этого первым параметром надо написать --search, затем выражение, пример: /help --search выражение.
- Обновлена функция handle_plugin в файле handling_plugins.py до актуальной версии.
- Удалено поле initializations в классе Data, т.к появилась удобная альтернатива этому.
- Добавлен новый параметр в config.ini, а именно dev_mode. Если задать true, то будет доступно динамическое обновление(или же горячее обновление. Hot reload), при котором, если изменить файлы в плагинах, скрипт это подловит и перезагрузит плагин, без надобности перезапускать скрипт в целом.
